# Niles North Computer Science Honors Society

This repository contains the static website for the Niles North Computer Science Honor Society.

## Files

- `index.html` — main landing page
- `member-emails.html` — member contact page

## Local preview

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub workflow

To fork this project on GitHub:

1. Click the Fork button on the repository page.
2. Clone your fork locally.
3. Make changes and push to your fork.
4. Open a pull request if you want to contribute back.
